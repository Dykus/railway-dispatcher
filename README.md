# ЖД Диспетчерская

Веб-приложение для учёта движения железнодорожных вагонов на промышленной станции.  
**Версия 5.3.1** – перепростой и штрафы в интерфейсе, московское время, улучшенная отчётность.

## Возможности

- **Наглядная визуализация** вагонов на путях с цветовой индикацией сроков.
- **Поддержка нескольких независимых площадок** (вкладки) – каждая площадка имеет свои пути, вагоны, историю, настройки штрафов.
- **Контроль глобальных и локальных сроков** с обратным отсчётом и предупреждением о просрочках.
- **Расчёт перепростоя и суммы штрафа**:
  - Фиксированная или прогрессивная шкала (до 3 диапазонов).
  - Отображается прямо в интерфейсе (в истории активных вагонов и в архиве).
  - Выгружается в Excel (сводка архива, индивидуальный отчёт, экспорт активных вагонов на текущую дату).
- **Полная история перемещений и архив** – каждое действие сохраняется, возможен поиск по номеру вагона.
- **Экспорт в Excel**:
  - Активные вагоны (с перепростоем на сегодня).
  - История перемещений (все вагоны или выборочно).
  - Архив (сводка и детализация, фильтрация по году/месяцу/периоду).
  - Индивидуальная история любого вагона.
- **Ролевая модель доступа**:
  - Наблюдатель (viewer) – только просмотр и выгрузка отчётов.
  - Диспетчер (dispatcher) – управление вагонами.
  - Супервизор (supervisor) – дополнительно редактирование вагонов, дат в истории, перенос вагонов между площадками.
  - Администратор (admin) – полный доступ, включая настройки, бэкапы, управление IP.
- **Резервное копирование** (автоматическое и ручное) с возможностью восстановления и копирования на сетевую папку.
- **Журнал действий** – аудит всех операций с возможностью экспорта в Excel.
- **Московское время (UTC+3)** – все даты отображаются в едином формате ДД-ММ-ГГГГ ЧЧ:ММ, не зависят от часового пояса сервера.
- **Персональная тёмная тема** – сохраняется в браузере каждого пользователя.
- **Работа без интернета** – определение IP через локальные вызовы.

## Установка и запуск

### Для разработки
1. Клонируйте репозиторий:  
   `git clone https://github.com/Dykus/railway-dispatcher.git`
2. Создайте виртуальное окружение:  
   `python -m venv venv`
3. Активируйте его:  
   `venv\Scripts\activate` (Windows)
4. Установите зависимости:  
   `pip install -r requirements.txt`
5. Запустите приложение:  
   `python run.py`

### Готовый EXE
Скачайте `RailwayDispatcher.exe` из раздела [Releases](https://github.com/Dykus/railway-dispatcher/releases) и запустите.
